# Randall AI Context

This folder is Randall's portable personal context for AI tools. It stores confirmed working preferences, project state, evidence, lessons, and safe inventory facts. It does not store secrets or full sensitive network configurations.

## Start every material task

1. Read the installer-created `LOCAL-STATE.md` to find the active personal context root.
2. Read `How to Work With Randall.md` once per session.
3. Read only the current project's `PROJECT.md`, `HANDOFF.md`, relevant decisions, and needed evidence.
4. Confirm facts against current files, tool output, or device readback when cheap and relevant.
5. Capture durable decisions, corrections, commitments, lessons, and verified results while working.

The initial context root is normally `~/.local/share/randall-ai/personal`. A later installation may select an external vault. `LOCAL-STATE.md` is the current pointer, so project files should not hardcode either location.

## Knowledge rules

- One file owns each current fact.
- Every durable decision, correction, lesson, commitment, and verified result includes a source ID and date.
- Keep confirmed fact, observation, inference, proposal, and unknown separate.
- Handoffs hold moving state. Decisions and lessons stay in their durable owners.
- Never store passwords, tokens, private keys, community strings, recovery codes, or unredacted sensitive configurations here.
- A saved setting is not proof it works. Record a controlled run or readback.

Start with `Projects/AI-Setup/PROJECT.md` for the training setup.
